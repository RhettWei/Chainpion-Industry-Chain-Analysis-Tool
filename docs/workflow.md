# 使用流程

## 1. 明确研究事件和范围

进入最新版网页，从首页选择演示案例或建立研究。确认行业、事件、研究截止日、观察窗口，以及关注的具体产品或业务。

以“AI算力设备需求增加10%”为例，先把它记录为行业事件假设，再分别设置具体产品销量、售价与成本变化。订单、交付和收入确认条件通过研究资料核对。

## 2. 阅读产业全景

在三维全景中查看上游、中游、下游及跨链支撑。选择节点后，在右栏阅读环节定义、产品、成本驱动、代表企业、经营指标与来源。

选择路径，阅读变化如何经过订单、采购、配置、价格或交付条件传递；同时检查成立条件与能改变判断的因素。

## 3. 选择量化方法

独立量化模块提供成本传导、量价—利润、本量利／盈亏平衡和市场事件研究。按问题选择模型后，为每个对象明确产品、成本项与是否受事件影响。

## 4. 准备并审核基准

每个字段可使用情景假设、资料提取或联网补齐。资料与联网路线先返回候选，保留机构／文件、摘录、单位、期间、披露日期和定位。

用户先审核候选，再确认整组基准。更换对象、业务范围、基线或研究时间后，重新审核对应输入。缺失值保留为缺口，数值零单独保存。

## 5. 调参与解释

调整受影响对象的销量、平均售价、单位成本、转嫁／让利、时滞或固定经营费用。计算结果随参数更新，图表与贡献解释读取同一组数值。

查看不同情景、敏感性与盈亏门槛；用户应能从一个毛利变化追回其销量收入、售价、成本或费用贡献。市场事件研究使用独立的证券、基准及交易日窗口。

## 6. 核对依据并交付

沿结论查看来源、业务范围与期间，记录下一步需要补充的订单、合同、BOM、分部财务、交付或产能证据。

保存研究版本后导出成果。独立量化服务支持Word、Markdown、HTML简版／详版；v1.7.3网页交付保留其原有冻结研究与导出方式。
