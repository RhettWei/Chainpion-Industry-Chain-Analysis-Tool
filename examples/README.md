# 同版经营情景

`compute-input.json`与`lithium-input.json`提取自Chainpion v1.7.3交付中的冻结研究输入。保留事件、研究范围、截止日、基线来源与逐对象参数；金额使用引擎万元口径。

| 案例 | 假设与业务范围 | 预期结果，元 |
| --- | --- | --- |
| 算力需求增长 | 算力设备产品收入100、成本70；销量+10%，平均售价及单位变动成本不变 | 收入110，成本75.6，毛利34.4 |
| 碳酸锂相关材料降价 | 电芯收入100、成本70；指定材料占营业成本20%，该材料单价-10%，售价与销量不变 | 收入100，成本68.6，毛利31.4 |

两例为规范化产品经营情景，研究截止日和观察窗口保留原记录。行业需求变化与产品销量参数分别设置。真实企业的使用应填入同范围、同期间的业务基线。

可在仓库根目录运行：

```bash
node examples/recalculate.mjs
```

该脚本通过与服务相同的`computeQuant`入口计算，并检查上述数值。四模型另外各有一份可提交的虚构／合成案例，位于`quant-module/examples/`。
